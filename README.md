# Blue Stone Import

ระบบคุมการตัดเงินและบันทึกปูนเข้า ของ **BLUE STONE TRADING CO., LTD.**

หน้าเว็บเดียวจบ ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ก็ใช้ได้ทันที
ข้อมูลเก็บในเบราว์เซอร์ และจะซิงก์ขึ้นฐานข้อมูล Supabase เมื่อเชื่อมต่อแล้ว

## สิ่งที่ระบบทำได้

- **คุมการตัดเงิน** เครดิตสองฝั่ง (โรงงานฝั่งลาว และผู้ซื้อ) วงกลมสัดส่วนคงเหลือ ตารางเทียบว่าเหลือเงินนำเข้า/ส่งมอบได้อีกกี่ตันกี่คันรถ แยกปูนผงกับปูนถุง
- **สรุปรายเดือน** เงินเข้า-ออกของแต่ละฝั่ง และยอดคงเหลือสิ้นเดือน
- **บันทึกปูนเข้า** จับคู่รถฝั่งลาวกับฝั่งไทยเป็นคู่ ๆ เก็บผู้ประกอบการ ทะเบียน พนักงานขับรถ เบอร์โทร น้ำหนักชั่งได้สองฝั่ง เวลารับปูนและเวลาออกจากด่าน ติ๊กผ่านเครื่องเอกซเรย์รายคู่
- **ลูกค้าปลายทาง** ทะเบียนลูกค้าพร้อมเลขนิติบุคคล ที่อยู่ไทยครบ 77 จังหวัด 928 อำเภอ 7,438 ตำบล เติมรหัสไปรษณีย์อัตโนมัติ และหมุดพิกัด GPS ลากปรับตำแหน่งได้
- **สร้างข้อความส่งงาน** แยกข้อความถึงพนักงานขับรถ (พร้อมลิงก์ถ่ายรูป 3 ขั้นตอน) และข้อความแจ้งลูกค้า
- **ค่าชิปปิ้ง** ฝั่งลาวคิดตามขั้นจำนวนรถ ฝั่งไทยคิดเหมาต่อคันหรือตามน้ำหนัก
- **ส่งออกข้อมูล** TSV / CSV / Markdown / JSON พร้อมหน้าวิเคราะห์
- **ผู้ใช้งานและประวัติการแก้ไข** เพิ่มผู้ใช้ สลับผู้ใช้ และบันทึกว่าใครแก้อะไรเมื่อไหร่

## ตั้งค่า Supabase

1. สร้างโปรเจกต์ใหม่ที่ [supabase.com](https://supabase.com) เลือก region ที่ใกล้ไทยที่สุด (Singapore)
2. เปิด **SQL Editor → New query** วางเนื้อหาทั้งหมดของไฟล์ [`supabase/schema.sql`](supabase/schema.sql) แล้วกด **Run**
3. ไปที่ **Project Settings → API** คัดลอกสองค่านี้
   - **Project URL** เช่น `https://xxxxxxxx.supabase.co`
   - **anon public** key (ห้ามใช้ `service_role`)
4. เปิดเว็บ → หน้า **ตั้งค่าอัตรา** → หัวข้อ **ฐานข้อมูลกลาง Supabase** วางสองค่านั้นแล้วกด **เชื่อมต่อและบันทึกค่า**

ค่าที่กรอกเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น ไม่ได้ฝังลงในโค้ดและไม่ได้ขึ้น GitHub

เมื่อเชื่อมต่อแล้ว ทุกครั้งที่บันทึกข้อมูลระบบจะส่งขึ้นฐานข้อมูลให้เองภายใน 1.5 วินาที
และมีปุ่ม **ส่งข้อมูลขึ้น** กับ **ดึงข้อมูลลง** ไว้สั่งเองได้

### ข้อควรระวังเรื่องสิทธิ์

สคริปต์ตั้งต้นเปิดให้ anon key อ่านและเขียนได้ทุกตาราง เพื่อให้ใช้งานได้ทันทีโดยยังไม่ต้องทำระบบล็อกอิน
**ใครที่ได้ URL กับ anon key ไปจะอ่านและแก้ข้อมูลได้ทั้งหมด** เมื่อพร้อมใช้งานจริงควรเปิด Supabase Auth
แล้วสลับไปใช้นโยบายชุดที่คอมเมนต์ไว้ท้ายไฟล์ `schema.sql` ซึ่งจำกัดเฉพาะผู้ที่ล็อกอิน

## Deploy ขึ้น Vercel

1. Import repo นี้เข้า Vercel
2. Framework Preset เลือก **Other** — ไม่ต้องตั้ง build command เพราะเป็นไฟล์ static
3. Output directory ปล่อยว่าง (ใช้ root)
4. ตั้งชื่อโปรเจกต์เป็น `bluestone-import` จะได้ `https://bluestone-import.vercel.app`

## ระบบเข้าสู่ระบบ

หน้า `login.html` ใช้ **Supabase Auth** แบบอีเมลกับรหัสผ่าน

1. ใน Supabase ไปที่ **Authentication → Providers** เปิด **Email** ไว้
2. ถ้าไม่ต้องการให้ใครสมัครเองได้ ปิด **Allow new users to sign up**
3. เพิ่มผู้ใช้ที่ **Authentication → Users → Add user** กรอกอีเมลกับรหัสผ่านให้พนักงานแต่ละคน
4. ใส่ค่า Supabase ลงใน `config.js` (หรือกรอกในหน้าตั้งค่าอัตราของเว็บ)

เมื่อ `config.js` มีค่าแล้ว เปิด `index.html` โดยยังไม่ล็อกอินจะถูกส่งไป `login.html` อัตโนมัติ
และมีปุ่ม **ออกจากระบบ** อยู่ในกล่องโปรไฟล์มุมขวาบน

ถ้ายังไม่ได้ตั้งค่า Supabase ระบบยังใช้งานได้แบบเก็บข้อมูลในเครื่องเดียวโดยไม่ต้องล็อกอิน

## ติดตั้งเป็นแอปบนเครื่อง (PWA)

เปิดเว็บที่ deploy แล้ว จะติดตั้งลงเครื่องได้เหมือนแอปทั่วไป

- **Android / Chrome** กดปุ่ม "ติดตั้งเป็นแอปบนเครื่องนี้" ที่หน้าล็อกอิน หรือเมนูเบราว์เซอร์ → ติดตั้งแอป
- **iPhone / Safari** กดปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **คอมพิวเตอร์ / Chrome, Edge** กดไอคอนติดตั้งที่แถบที่อยู่

ไอคอนเป็นโลโก้บนพื้นขาวมีวงแหวนเขียว เพื่อให้แยกจากแอปเว็บหลักที่เป็นพื้นขาวล้วน
มี service worker เก็บหน้าเว็บไว้ในเครื่อง เปิดใช้งานต่อได้แม้สัญญาณขาด
ส่วนข้อมูลจาก Supabase จะดึงสดเสมอ ไม่ถูกแคช

## โครงสร้างไฟล์

```
index.html             หน้าเว็บทั้งระบบ รวม CSS, JS, ข้อมูลที่อยู่ไทย และโลโก้ ไว้ในไฟล์เดียว
login.html             หน้าเข้าสู่ระบบ ต่อกับ Supabase Auth
config.js              ค่า Project URL และ anon key ของ Supabase
manifest.webmanifest   ข้อมูลแอปสำหรับติดตั้งลงเครื่อง
sw.js                  service worker สำหรับใช้งานออฟไลน์
icons/                 ไอคอนแอป 192, 512, maskable และ apple-touch
supabase/schema.sql    สคริปต์สร้างตารางและนโยบายสิทธิ์
vercel.json            ตั้งค่า deploy แบบ static
```
