ขั้นที่ 1 · ใส่คีย์ลง config.js
-----------------------------------------------------------
เปิดไฟล์ config.js ด้วย Notepad แล้วเติมคีย์ในช่อง key ให้เป็น

  window.BS_CONFIG = {
    url: 'https://eoirzsvknmnjgsuvwzjz.supabase.co',
    key: 'sb_publishable_xxxxxxxxxxxxxxxx'
  };

คีย์ที่ใช้คือ Publishable key หรือ anon public key เท่านั้น
คัดลอกได้ที่
https://supabase.com/dashboard/project/eoirzsvknmnjgsuvwzjz/settings/api-keys

ห้ามใส่ service_role หรือ sb_secret_ เด็ดขาด

หมายเหตุ: พอใส่คีย์แล้ว เปิด index.html ในเครื่องจะเด้งไปหน้าล็อกอินทันที
ต้องทำขั้นที่ 4 ให้เสร็จก่อนจึงจะเข้าได้


-----------------------------------------------------------
ขั้นที่ 2 · ส่งโค้ดขึ้น GitHub
-----------------------------------------------------------
ดับเบิลคลิกไฟล์  push.bat  ในโฟลเดอร์นี้ แล้วทำตามที่หน้าจอบอก

ครั้งแรกจะมีหน้าต่าง GitHub ขึ้นมาให้ยืนยันตัวตน
เลือก "Sign in with your browser" แล้วล็อกอินตามปกติ
ไม่ต้องใช้ token ที่เคยสร้างไว้ และควรเข้าไปลบ token เก่าทิ้งที่
https://github.com/settings/tokens

ถ้าเครื่องยังไม่มี Git ให้ติดตั้งก่อนที่
https://git-scm.com/download/win  (กด Next ผ่านได้ทุกหน้า)


-----------------------------------------------------------
ขั้นที่ 3 · ต่อ Vercel
-----------------------------------------------------------
1. เข้า https://vercel.com/new  แล้วล็อกอินด้วยบัญชี GitHub
2. เลือก repo  Bluestone-import  กด Import
3. ไม่ต้องตั้งค่าอะไรเพิ่ม กด Deploy ได้เลย (เป็นเว็บไฟล์ธรรมดา)
4. รอสักครู่จะได้ลิงก์ เช่น  https://bluestone-import.vercel.app

ครั้งต่อ ๆ ไปแค่ดับเบิลคลิก push.bat อีกครั้ง Vercel จะอัปเดตเองอัตโนมัติ

ขั้นที่ 4 · เปิดระบบล็อกอินและเพิ่มผู้ใช้
-----------------------------------------------------------
1. https://supabase.com/dashboard/project/eoirzsvknmnjgsuvwzjz/auth/providers
   เปิด Email ไว้  และ "ปิด" Allow new users to sign up
   (ปิดเพื่อไม่ให้คนนอกสมัครเข้ามาเอง)

2. https://supabase.com/dashboard/project/eoirzsvknmnjgsuvwzjz/auth/users

   ติ๊ก Auto Confirm User ด้วย จะได้ไม่ต้องรอยืนยันอีเมล

3. เปิดลิงก์ Vercel ทดสอบล็อกอิน

ขั้นที่ 4.5 · สร้างตารางเก็บรูปจากคนขับ
-----------------------------------------------------------
เปิด https://supabase.com/dashboard/project/eoirzsvknmnjgsuvwzjz/sql/new
คัดลอกไฟล์  supabase\schema-photos.sql  ทั้งไฟล์ไปวาง แล้วกด Run
รันซ้ำได้ ไม่พัง  ถ้าเคยรันแล้วจะเติมเฉพาะคอลัมน์ที่ยังไม่มี

หน้าเว็บที่เกี่ยวข้อง
  d.html       หน้าคนขับถ่ายรูปส่ง (เปิดจากลิงก์ในข้อความใบงาน)
  photos.html  หน้าออฟฟิศดูรูปย้อนหลัง (ต้องล็อกอิน)
  board.html   จอคู่รถสำหรับทีวี (ต้องล็อกอินครั้งเดียวต่อเครื่อง)

-----------------------------------------------------------
ขั้นที่ 6 · ติดตั้งเป็นแอปบนมือถือ
-----------------------------------------------------------
Android : เปิดลิงก์ Vercel ใน Chrome > เมนูจุดสามจุด > ติดตั้งแอป
iPhone  : เปิดใน Safari > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม

ไอคอนเป็นพื้นขาววงแหวนเขียว แยกจากไอคอนเว็บเดิมของบริษัท


-----------------------------------------------------------
การย้ายข้อมูลข้ามเครื่อง
-----------------------------------------------------------
ในหน้า "ส่งออกข้อมูล" ท้ายหน้ามีหัวข้อ "สำรองและย้ายข้อมูลทั้งระบบ"
  - กดคัดลอกข้อมูลทั้งระบบ ที่เครื่องต้นทาง
  - ไปวางในช่องนำเข้าที่เครื่องปลายทาง แล้วกดนำเข้า
ใช้ตอนย้ายข้อมูลจากแอปทดลองมาที่เว็บจริง หรือเก็บสำรองไว้กันพลาด
